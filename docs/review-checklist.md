# Review Checklist

## 1. Requirements / 需求
- [ ] Соответствует ли код требованию FR-001?

## 2. Tests / 测试
- [ ] Добавлены ли юнит-тесты?

## 3. Style / 代码风格
- [ ] Есть ли namespace?
- [ ] Нет ли неиспользуемых using?

## 4. Documentation / 文档
- [ ] Есть ли XML-документация к классу?

## 5. Bug-risk / 潜在bug
- [ ] Есть ли проверка на null?

## 6. Commit message / 提交信息
- [ ] Понятно ли из сообщения, что сделано?
